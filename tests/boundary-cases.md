# Boundary Cases

最低限検証する境界ケース：

## 1. 暦日・時間境界
- 月初 / 月末
- 年末 / 年始
- 年度末 / 年度初
- 閏年2月29日
- 勤務開始時刻 / 勤務終了時刻
- 休憩開始直前 / 休憩終了直後

## 2. 休暇・制度境界
- 最小休暇単位 / 最大取得単位
- 残日数0ちょうどでの申請・再申請
- 短時間勤務・変形労働時間制
- 週休日 / 休日 / 代休日 / 振替休日

## 3. ワークフロー・整合性境界
- `approval_cycle` 初回（Cycle 1）から再申請（Cycle 2以上）への移行
- 並行重複送信（Concurrent duplicate submission）時の楽観ロック・409競合
- 複合トランザクション境界（AuditLog書き込み直前、残数更新直前の例外発生ロールバック）
- DB外副作用（PDF生成、通知）失敗時のDBコミット非巻き込み境界
