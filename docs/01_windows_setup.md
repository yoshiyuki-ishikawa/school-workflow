# Windows サーバー導入・運用手順書

本システムは、学校現場の職員室等にある一般的な Windows PC をローカルサーバーとして稼働させ、校内LANに接続されたすべての教職員PC（Windows / Mac / タブレット等）から利用できる設計となっています。

---

## 1. 事前準備 (親機 Windows PC)

1. **Node.js のインストール**:
   - [Node.js 公式サイト (LTS版推奨)](https://nodejs.org/) よりインストーラーをダウンロードしてインストールします。
   - ※ すでに Node.js が導入されている環境では再インストール不要です。

2. **配布パッケージの配置**:
   - 配布された `school-workflow` フォルダを、Cドライブの任意の場所（例: `C:\school-workflow`）に配置します。

---

## 2. サーバーの起動方法

1. `C:\school-workflow\scripts\start-windows.bat` をダブルクリックします。
2. コマンドプロンプト（黒い画面）が立ち上がり、以下のように案内が表示されます。

```text
==================================================
  学校業務ワークフローシステム が起動しました
==================================================
  ローカル接続先:   http://localhost:3000
  校内LAN接続先:    http://192.168.1.50:3000
--------------------------------------------------
  PoCモード:        有効 (クイック切替利用可)
  データ保存場所:   C:\school-workflow\data\school_workflow.db
  バックアップ保存: C:\school-workflow\backups
==================================================
```

3. **表示された「校内LAN接続先（例: `http://192.168.1.50:3000`）」を、他の先生方に共有します。**

---

## 3. クライアントPCからの接続方法

1. 校内LAN（Wi-Fiまたは有線LAN）に接続したPCやタブレットのブラウザ（Google Chrome / Microsoft Edge / Safari 等）を開きます。
2. アドレスバーに `http://192.168.1.50:3000`（親機に表示されたアドレス）を入力します。
3. ログイン画面が表示されたら、各自のID/パスワードでログインします。
   - （ブラウザのお気に入り/ブックマークに登録しておくと便利です）

---

## 4. サーバーの停止方法

* 起動している黒い画面上で `Ctrl + C` を押すか、ウィンドウ右上の「×」ボタンをクリックして閉じます。
