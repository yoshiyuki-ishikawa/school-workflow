- **リポジトリパス**: `/Users/ishikawayoshiyuki/Documents/Antigravity/school-workflow`
- **技術スタック**:

  - **Frontend**: React 18 + Vite + Tailwind CSS + Lucide React (完全ローカルバンドル)
  - **DBパス**: `school-workflow/data/school_workflow.db` (全11テーブル構築済)
  - **バックアップ**: `school-workflow/backups` (`VACUUM INTO` + `PRAGMA integrity_check`)
- **稼働ポート**: `http://localhost:3000` (校内LAN: `http://192.168.1.254:3000`)
- **テスト通過状況**: 包括的単体テスト（3件PASS）、E2E HTTP統合テスト（4件PASS）全テスト合格。

### 1.2 実装済み機能（第0〜3世代）
1. **憲法・基本機能**:
   - サーバー正、Server Time Authority、自己承認禁止（403）、楽観的排他制御（version）、独立監査ログ（AuditLog）。
2. **第9号様式 休暇簿**:
   - 1日7時間45分（8:10〜16:40）基準の時間休計算、年休残数（20日付与基準）・各種休暇累計の自動積算。
3. **別表第一 旅行命令・依頼簿**:
   - 出張3段階決裁（教頭 → 校長 → 事務係）、旅行命令発令（`TRIP_APPROVED`）、出張後復命書（結果報告）提出・復命3段階決裁完了（`FINAL_APPROVED`）。
4. **第6号様式 出勤簿**:
   - カレンダーグリッド（1日〜31日）への決裁データ自動マッピング（略号印: 年休, 病休, 特休, 職免, 出張, 週休, 休日, 代休）。
   - 土日祝の行事勤務日変更 ＆ 平日の代休・週休振替機能。
   - 月別集計表自動計算 ＆ 校長月次確定（電子押印サイン）。

## 2. 新規会話で実施する「Step 1」の要件定義

次の会話では、現場実用化の第一歩として以下の **4大機能** を実装・完成させます。

### ① 公文書帳票の完全A4 PDF出力エンジン (Print / PDF)
- ブラウザの通常印刷に加え、紙の公文書と寸分違わぬ美しい罫線・フォント・配置で出力するA4帳票出力機能。
  - **帳票1**: 「第9号様式 休暇簿」A4縦
  - **帳票2**: 「別表第一 旅行命令・依頼簿」A4横
  - **帳票3**: 「第6号様式 出勤簿（表・裏）」A4縦

### ② 代理申請機能 (教頭・学年主任による代行)
- 急な病欠・忌引や出張等で本人がPCを開けない場合、管理職（教頭・校長）または事務係が「申請対象教職員」を選択して代理作成・提出できる機能。
- 申請データおよび監査ログに「代理申請者（代行者）」と「本人（対象教職員）」の双方が明記・記録される。

### ③ 複数名一括出張申請機能
- 部活動引率、修学旅行、学年会、教科研修会等で、複数の教職員が同一の用務先・日程・目的で出張する場合、1回の申請で複数教職員の旅行命令・復命を同時生成・決裁できる機能。

### ④ リアルな名字入り電子印影（認印スタンプ）
- 承認・決裁時、ステップ履歴および出勤簿・帳票上に、赤色の「名字入り丸型認印」（例: `[ 田中 ]` `[ 鈴木 ]` + 承認日付）がビジュアルとして押印されるUIコンポーネント。
