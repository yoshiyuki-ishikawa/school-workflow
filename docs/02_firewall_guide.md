# Windows Defender ファイアウォール設定ガイド

親機となる Windows PC でサーバーを起動した際、他のPCから接続できない場合は、Windows Defender ファイアウォールによってポート 3000 の通信がブロックされている可能性があります。以下の手順で許可を設定してください。

---

## 1. 初回起動時の警告ダイアログの場合

`start-windows.bat` を初めて実行した際、「Windows セキュリティの重要な警告（このアプリの機能のいくつかがブロックされています）」という画面が表示される場合があります。

1. **「プライベート ネットワーク（ホーム ネットワークや社内・校内ネットワークなど）」に必ずチェック** を入れます。
2. 「アクセスを許可する」ボタンをクリックします。

---

## 2. 手動でポート 3000 を開放する場合の手順

もし警告が表示されなかった場合や接続できない場合は、以下の手順で手動設定します。

1. **ファイアウォール設定を開く**:
   - スタートメニューで「セキュリティが強化された Windows Defender ファイアウォール」と検索して開きます。

2. **受信の規則を追加**:
   - 左側メニューの「受信の規則」をクリック。
   - 右側メニューの「新しい規則...」をクリック。

3. **規則の種類**:
   - 「ポート」を選択し「次へ」。

4. **プロトコルおよびポート**:
   - 「TCP」を選択。
   - 「特定のローカル ポート」に `3000` を入力し「次へ」。

5. **操作**:
   - 「接続を許可する」を選択し「次へ」。

6. **プロファイル**:
   - 「プライベート」および「ドメイン」にチェック（「パブリック」はセキュリティ上オフ推奨）し「次へ」。

7. **名前**:
   - 名前欄に `学校業務ワークフロー (ポート3000)` と入力し「完了」をクリックします。

以上で、校内LAN内の他のPCから `http://<親機のIP>:3000` で接続できるようになります。
