# 学校業務ワークフロー（服務管理）法規・条例・規則 準拠定義書

> **適用基準**:
> 1. **条例**: 山口県 学校職員の勤務時間、休日、休暇等に関する条例（昭和46年条例第30号 / 最新改正: 令和7年条例第39号）
> 2. **規則**: 山口県人事委員会規則第八号 学校職員の勤務時間、休日、休暇等に関する規則（平成7年規則第8号 / 最新改正: 令和8年規則第18号）

---

## 1. 職種・権限と決裁ルート定義

### 1.1 職員区分（条例第2条）
- **教育職員**: 給特法第2条第2項に規定する教員。原則として時間外勤務手当対象外・超勤4項目のみ時間外命令可能。
- **事務職員・学校栄養職員・技術職員等**: 給料・時間外勤務手当（学校職員給与条例）の対象。
- **短時間勤務学校職員 / 育児短時間勤務学校職員等**: 勤務時間・休暇日数の按分計算対象。

### 1.2 承認・決裁権限（条例第20条・規則第22条 読替え規定）
- **県立学校職員**: 校長承認 ➔ 山口県教育委員会
- **市町立学校職員**: 校長承認 ➔ **市町教育委員会**

## 2. 勤務時間・週休日・振替・代休ルール

### 2.1 勤務時間（条例第3条・規則第3条）
- 1週間につき **38時間45分**（1日 **7時間45分**）。
- 休憩時間（条例第4条・規則第5条）:
  - 6時間超 ➔ 45分以上
  - 7時間45分超 ➔ 1時間以上（原則一斉付与）

### 2.2 週休日の振替等（条例第3条第8項・規則第4条）
- **振替可能期間**: 勤務を命ずる日を起算日として **「4週間前 〜 8週間後」**（特殊事由時16週間）。
- **振替単位**: 1日（7時間45分）または 半日相当（3時間15分 〜 4時間30分）。
- **制約条件**:
  - 4週間につき **4日以上の週休日** を確保。
  - 連続勤務日数は **24日以内**。

### 2.3 代休日の指定（条例第7条・規則第7条）
- 休日（祝日法・年末年始）に勤務を命じた場合、**当該休日を起算日として8週間以内** の勤務日等を代休日として指定。

### 2.4 時間外勤務・業務量管理（条例第8条, 第8条の2 / 規則第8条）
- **教員の時間外勤務命令（超勤4項目制限）**:
  1. 校外実習その他生徒の実習に関する業務
  2. 修学旅行その他学校の行事に関する業務
  3. 職員会議に関する業務
  4. 非常災害・緊急指導・その他やむを得ない業務
- **限度時間（一般）**: 月 **45時間** / 年 **360時間**。
- **指定所属（特別上限）**:
  - 月 **100時間未満** / 年 **720時間以内**
  - 月45時間超は年 **6か月以内**
  - 複数月平均（2〜6か月平均）で月 **80時間以内**。

## 3. 休暇制度と計算・バリデーション仕様

### 3.1 年次有給休暇（条例第12条・規則第8条の2〜第11条）
- **基本付与**: 年 **20日**（翌年繰越は最大20日 / 合計最大40日）。
- **取得単位**: 1日、半日、1時間（1日 = 7時間45分換算）。
- **中途採用者付与（規則別表第一）**:
  - 1月:20日 / 2月:18日 / 3月:17日 / 4月:15日 / 5月:13日 / 6月:12日 / 7月:10日 / 8月:8日 / 9月:7日 / 10月:5日 / 11月:3日 / 12月:2日
- **臨時的任用職員付与（規則別表第二）**:
  - 1月以上2月未満:2日 〜 12月:20日（任用更新時は期間通算）。

### 3.2 特別休暇（条例第14条・規則第13条）
- **選挙・公民権行使 / 裁判員等出頭**: 必要期間（有給）
- **結婚休暇**: 連続する **7日**
- **忌引休暇（規則別表第三）**:
  - 配偶者・父母: 10日 / 子: 7日 / 祖父母・孫・兄弟姉妹: 5日 / 曾祖父母・叔父叔母: 3日
  - ※祭具等の承継（代襲相続）や生計同一要件により加算あり。
- **夏季休暇**: 7月〜9月の期間内に **4日**（短時間勤務者は2日）。
- **産前・産後休暇**: 産前8週（多胎14週）、産後8週。
- **配偶者出産休暇**: **3日** / **育児参加休暇**: **5日**。
- **子の看護等休暇**: 中学校就学前まで。年 **5日**（2人以上なら **10日**）。
- **短期介護休暇**: 要介護者1人につき年 **5日**（2人以上なら **10日**）。
- **不妊治療休暇**: 年 **6日**（体外受精等は **10日**）。
- **生理休暇**: 1回につき **3日**。
- **災害・交通遮断**: 被災復旧7日、出勤困難・危険回避は必要期間。

### 3.3 介護休暇・介護時間（条例第15条・第16条 / 規則第14条〜第14条の3）
- **介護休暇（無給・減額）**:
  - 対象家族1人につき通算 **6か月**（指定期間内、**最大3回** 分割）。
  - 初回申請は原則 **2週間以上** の一括請求。
- **介護時間（無給・減額）**:
  - 対象家族1人につき連続 **3年間**、1日につき **2時間** 以内（30分単位）。

### 3.4 子育て支援部分休暇（条例第17条 / 規則第14条の4・第14条の5）
- **対象**: 小学校1年生〜3年生の子を養育する職員。
- **事前申出（年度ごとに枠を選択）**:
  - **第1号枠**: 1日につき **2時間** 以内（30分単位。保育時間・介護時間等との合算2h上限）。
  - **第2号枠**: 1年につき **77時間30分** 以内（原則1時間単位）。

### 3.5 ライフイベント面談・意向確認（条例第16条の2, 第17条の2 / 規則第14条の6）
- **介護意向確認**: 職員が40歳に達した年度に情報提供。要介護者申出時に面談実施。
- **育児期両立支援意向確認**: 子が **1歳11か月翌々日 〜 2歳11か月翌日** の間に面談・意向確認を実施。

## 4. システム実装・改修時の強制ルール (Guardian / Architect Rule)
1. **本ドキュメントの常時参照**:
   ワークフローのテーブル定義、APIバリデーション、UIフォームの選択肢や計算ロジックを変更する際は、必ず本法規定義書と照合すること。
2. **自己承認の完全排除**:
   校長・教頭であっても自身の申請を自ら決裁することは不可（代決・上位決裁ルールを適用）。
3. **監査ログの保全**:
   条例・規則に反する申請（超勤4項目外の申請、日数超過、期間外振替等）が試行された場合は、適切なエラーを返しつつ監査ログに記録すること。
