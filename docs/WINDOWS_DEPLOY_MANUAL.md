# 公立小中学校 服務管理システム Windows親機 導入・運用・完全復旧マニュアル

本マニュアルは、インターネットから完全に隔離された学校LAN（閉域網）環境において、Windows PC（親機）1台をサーバーとして設置し、第三者がマニュアルの手順のみでシステムの導入・運用・バックアップ・新PCへの完全復旧を行うための手順書です。

---

## 1. システム構成と動作要件

*   **親機（サーバー）**: Windows 10 / 11（x64）
    *   管理者権限は**原則不要**（ユーザーフォルダ内で起動可能）
    *   Node.js は配布パッケージ内の `bin/node.exe` に同梱されているため、**追加インストール不要**
*   **子機（教職員端末）**: 校内LANに接続されたPC / タブレットのモダンブラウザ（Edge / Chrome）
*   **通信環境**: 完全オフライン（外部通信ゼロ）

---

## 2. 導入手順（ワンクリックセットアップ）

1.  **配布パッケージの配置**:
    - USBメモリ等の安全な媒体から、親機の任意のフォルダ（例: `C:\SchoolWorkflow`）へ配布ZIPを展開（解凍）します。
2.  **起動**:
    - 展開したフォルダ内の **`start-windows.bat`** をダブルクリックします。
    - 自動的に黒いウィンドウ（サーバー画面）が開き、既定のブラウザで `http://localhost:3000` が起動します。
3.  **初期ログイン**:
    - 管理者: ユーザー名 `admin` / パスワード `password123`
    - 校長: ユーザー名 `principal` / パスワード `password123`
    - 教頭: ユーザー名 `vice_principal` / パスワード `password123`
    - 教員A: ユーザー名 `teacher1` / パスワード `password123`
    - 教員B: ユーザー名 `teacher2` / パスワード `password123`

---

## 3. 校内LANからの接続設定（Windows Firewall）

他の職員室PCから親機にアクセスできるようにする場合のみ、親機側でポート `3000` の通信を許可します。

### ファイアウォール許可手順:
1.  親機の「スタート」→「Windows Defender ファイアウォール」を開きます。
2.  左側の「詳細設定」をクリックし、「受信の規則」を選択します。
3.  右側の「新しい規則」をクリックし、以下を設定します:
    - **規則の種類**: 「ポート」を選択
    - **プロトコルおよびポート**: 「TCP」「特定のローカル ポート: `3000`」を入力
    - **操作**: 「接続を許可する」を選択
    - **プロファイル**: 「プライベート」「ドメイン」にチェック
    - **名前**: 「学校服務管理システム (ポート3000)」と入力して「完了」
4.  親機のIPアドレス（例: `192.168.1.50`）を確認し、子機のブラウザから `http://192.168.1.50:3000` を開きます。

## 4. 日常のバックアップ運用

システムには自動整合性検証付きのバックアップ機能が備わっています。

*   **手動バックアップの実行**:
    - フォルダ内の **`backup.bat`** をダブルクリックします。
    - `backups/backup_YYYYMMDD_HHMMSS/` フォルダ内に、SQLite DB、設定情報、およびハッシュ検証用メタデータが一体となって保存されます。
*   **外部保存の推奨**:
    - 週末や学期末に、`backups` フォルダ内のバックアップフォルダを外部USBメモリ等へコピーして保管してください。

---

## 5. 新PCへの完全復旧手順（Disaster Recovery）

親機PCが物理故障・全損した場合でも、**新しいWindows PCへ即座に同一状態で復元**できます。

1.  **新PCの用意**:
    - 新しいWindows PCを用意し、元の配布パッケージZIPを展開します。
2.  **バックアップの配置**:
    - 旧PCから退避したバックアップフォルダ（例: `backup_20260831_120000`）を新PCの `backups\` フォルダに配置します。
3.  **リストア実行**:
    - コマンドプロンプトまたはバッチ実行にて以下を実行します:
      ```cmd
      restore.bat backups\backup_20260831_120000
      ```
    - 確認メッセージに対し `Y` を入力します。
    - チェックサム検証およびDB整合性チェックが自動実行され、復元が完了します。
4.  **運用再開**:
    - `start-windows.bat` をダブルクリックして起動します。
    - 過去の申請書、承認履歴、出勤簿、電子押印、および年休残高が100%同一の状態で即座に再開されます。

---

## 6. お問い合わせ・障害時対応

*   **データベース破損時**: システム起動時に自動で検知され、直前の安全な世代バックアップから復元するか、`restore.bat` を実行してください。
*   **停止方法**: `start-windows.bat` で開いた黒いコマンド画面で `Ctrl + C` を押し、`Y` を入力して終了します。
